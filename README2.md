# Team2-SPA-Project 

## Название проекта

**РумТибет** - Сайт по поиску туров и программ.

## Описание 

Мы представляем веб-сайт, который предназначен для облегчения планирования и бронирования туров. Наш ресурс предлагает интуитивно понятный интерфейс, позволяющий пользователям легко искать и выбирать туры, просматривать детализированные программы, оценивать стоимость, изучать рейтинги направлений и бронировать даты. Кроме того, в нижней части сайта (футере) мы собрали полезные ссылки, которые помогут начинающим путешественникам подготовиться к своим приключениям.

## Основные функции

**Поиск туров** Пользователи имеют возможность искать туры, выбирая локацию, даты и количество участников.
**Программа тура**  Доступен просмотр подробной программы тура.
**Стоимость**  Отображается стоимость тура и отдельных программ.
**Рейтинг направлений**  Пользователи могут просматривать популярные направления и их рейтинги, предоставленные другими путешественниками.
**Бронирование**  Доступно бронирование дат тура через специальную форму.
**Полезные ссылки**  В футере сайта представлены ссылки для начинающих путешественников, содержащие полезную информацию о подготовке к путешествиям.

## Технологии

•   HTML: Структура и контент веб-страниц.
•   CSS: Оформление и стилизация элементов.
•   JavaScript: Интерактивность и динамическое поведение.
•   Серверная часть: Node.js

## Установка и запуск

1.  Клонируйте репозиторий: https://github.com/agkondakov91/Team2-SPA-Project.git
2.  Для установки сервера следуете следующим шагам:
    - npm install
    - npm run dev
3.  Запускайте через расширение live server
4.  В открывшемся окне выберите папку public
5.  Сайт запущен. 🎉🎉Ура!!!🎉🎉
